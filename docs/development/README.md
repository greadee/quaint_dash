# Development Guide

Use these documents in order when joining or changing the project.

1. [Contributor onboarding](onboarding.md) explains the repository, runtime, and common extension
   points.
2. [Environment setup](environment.md) lists local configuration and provider bounds.
3. [Testing and verification](testing.md) defines focused, full-suite, browser, and data-health
   checks.
4. [Codebase map](../architecture/codebase-map.md) shows package ownership.
5. [Architecture index](../architecture/README.md) explains dependency and data boundaries.
6. [Contributing guide](../../CONTRIBUTING.md) records repository conventions.

For commands intended for day-to-day use rather than development, see the
[CLI reference](../reference/README.md).
