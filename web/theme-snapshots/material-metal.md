# material-metal

Reusable theme snapshot for the portfolio allocation material treatment.

Intent:

- Matte metallic dashboard allocation surfaces
- Premium color gradients with softened edge light
- Subtle pie-slice roundover
- Charcoal shell with restrained contrast

Primary implementation files:

- `web/src/routes/portfolioRoute.tsx`
- `web/src/styles.css`

Key identifiers:

- `piePalette`
- `AllocationPie()`
- `.allocation-pie-layout`
- `.allocation-pie-chart`
- `.allocation-swatch`
- `.allocation-center-value`
- `.allocation-center-label`

Notes:

- This snapshot is the approved base look before removing pie click interactions.
- Reuse this as the starting point when another surface needs the same metallic material language.
